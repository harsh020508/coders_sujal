# Unslop Skill - Applied to LocalKaam

This folder contains the unslop skill by @heydamir that was used to redesign the LocalKaam platform.

## What is Unslop?

unslop turns vibecoded, AI-looking UI into a designed interface with its own character. It removes the predictable signs of AI-generated design:
- Generic headlines that could fit any product
- Emoji used as icons
- Colored badges and glows
- Hype words and exclamation marks
- Inconsistent spacing
- Too many font weights
- Looping animations

## LocalKaam Direction

**Product**: Connects homeowners with verified local tradespeople in Mumbai for immediate home repairs.

**Character**: Direct, reliable, neighborhood-focused.

**World**: Mumbai neighborhoods, street-level service, verification badges, distance markers.

**Moments**: Live map with distance rings, verification timeline, earnings charts.

**Signature**: Distance rings, verification checkmarks, ₹ symbol.

## 9 Passes Applied

1. **Spacing** — 4px grid everywhere
2. **Color** — Graphite ramp + warm amber accent
3. **Icons** — Lucide only, consistent size
4. **Copy** — Specific to LocalKaam, no hype
5. **Type** — 3 weights, sentence case
6. **Layout** — Kept structure, improved hierarchy
7. **Details** — Quiet counts, nested radius
8. **Visuals** — Product moments, no filler
9. **Motion** — Named transitions, one easing
